# Git 팀 협업 연습

## 프로젝트 목적

GitHub Flow를 기반으로 브랜치, PR, 코드 리뷰,
충돌 해결과 Git 트러블슈팅을 연습합니다.

## 결과물

팀원별 소개 문서와 협업 과정 기록을 작성합니다.

## 폴더 구성

- docs/: 협업 가이드와 실습 기록
- src/: 코드 또는 예시 파일
- team/: 팀원별 소개 문서

## 브랜치 전략

작업별 feature 브랜치를 만들고 PR과 리뷰를 거쳐 main에 병합합니다.
main을 안정적으로 유지하면서 서로의 변경 사항을 검토하기 위해 GitHub Flow를 사용합니다.
