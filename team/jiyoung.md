# 이지영

## 소개

React와 JavaScript 기반 웹 서비스 개발 경험이 있으며, 프론트엔드를 넘어 백엔드와 AI 서비스 개발로 역량을 확장하고자 하는 이지영입니다.

## 관심 분야

- 웹 서비스 및 풀스택 개발
- AI 및 데이터 기반 서비스 개발

## 이번 과제의 학습 목표

- Issue와 PR을 연결해 작업 기록 남기기
- 팀원의 변경 사항을 검토하고 구체적인 리뷰 작성하기
- 리뷰 의견을 반영하고 충돌 해결 과정 익히기
- 같은 파일의 동일한 부분을 서로 다르게 수정하여 Git 충돌 실습하기
- 충돌 발생 원인과 해결 과정, 결과를 docs/conflict-resolution.md에 기록하기
